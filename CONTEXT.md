## Project: Copeepl

Family-trust platform helping parents and carers find companies
that genuinely support family life.

## Tech Stack

- Next.js 14 (App Router, TypeScript)
- Supabase (auth, database, storage)
- Tailwind CSS
- Vercel (deployment)
- Stripe (payments)
